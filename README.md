# Noke Games

Sitio público y genérico del estudio independiente Noke Games.

## Etapas públicas de los proyectos

La sección de proyectos muestra una ruta común de cinco etapas para comunicar
avances grandes sin prometer fechas ni porcentajes:

1. Preproducción
2. Base jugable
3. Base online
4. Pruebas cerradas
5. Preparación de lanzamiento

Cada actualización debe cambiar, en conjunto, la etapa actual, el resumen de lo
que se está construyendo, el próximo hito y la fecha. Las barras y las fechas
están en `index.html`; los textos de los 18 idiomas están agrupados en
`progressTranslations`, dentro de `translations.mjs`.
